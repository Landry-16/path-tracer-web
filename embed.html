Use the path tracer in your own project

Everything the editor does is available as a library: a viewer, the full editor and path traced material previews. Pick the integration that fits your stack. All three share the same JSON scene format, so a scene made in the editor drops straight into any of them.

  • Web componentsOne script tag, works in plain HTML, React, Vue, Svelte.
  • IframeZero code: paste a link, isolated from your page.
  • ES moduleFull API for bundlers, typed with TypeScript.

Web components

Load the bundle once, then use the elements anywhere. Each element renders inside a shadow root, so your CSS and theirs never collide.

<pt-viewer>

Move the pointer over the image: light-follow makes the ceiling light track it. Drag to orbit, right drag to pan, scroll to zoom.

src
URL of a scene JSON (exported from the editor).
preset
studio, cornell, roughness, materials, primitives, empty.
light-follow
The light follows the pointer.
controls="false"
Static image, no camera input.
max-samples, exposure, resolution-scale
Quality and look.
<pt-viewer preset="cornell" light-follow style="height: 360px"></pt-viewer>

<!-- or with your own scene, inline or by URL -->
<pt-viewer src="/scenes/product.json"></pt-viewer>
<pt-viewer>
  <script type="application/json">{ "objects": [...], "lights": [...] }</script>
</pt-viewer>

<pt-material-preview>

Path traced material balls. Every preview on a page shares one WebGL context, so a catalogue of dozens stays cheap.

<pt-material-preview preset="gold"></pt-material-preview>
<pt-material-preview material='{"baseColor":"#c23b22","roughness":0.3}'></pt-material-preview>

<script type="module">
  const preview = document.querySelector("pt-material-preview");
  preview.material = { baseColor: "#1d3f9c", metallic: 0, roughness: 0.4, clearcoat: 1 };
</script>

<pt-editor>

The complete editor, sized by its container. Listen to pt-change to save scenes in your own backend.

Edit something above: the latest pt-change event will show up here.

<pt-editor src="/scenes/room.json" style="height: 640px"></pt-editor>

<script type="module">
  const editor = document.querySelector("pt-editor");
  editor.addEventListener("pt-change", (event) => {
    fetch("/api/scenes/42", { method: "PUT", body: JSON.stringify(event.detail.scene) });
  });
</script>

Iframe

viewer.html shows a scene full window. In the editor, the Embed button generates the link for your current scene. Query options: preset, src, controls=0, follow=1, ui=0, samples=N.

The parent page can drive it with postMessage: { type: "pt:set-scene", scene } replaces the scene and { type: "pt:snapshot" } answers with a PNG blob.

ES module

Install from GitHub (the package builds itself on install), then import what you need. Types are included.

npm install github:Landry-16/path-tracer-web
import { Viewer, Editor, createScene, createMaterial, createObject, createLight, renderMaterialPreview } from "path-tracer-web";

// A scene from code
const gold = createMaterial({ name: "Gold", baseColor: "#ffd27a", metallic: 1, roughness: 0.15 });
const scene = createScene({
  materials: [gold],
  objects: [createObject("sphere", { position: [0, 0.5, 0], materialId: gold.id })],
  lights: [createLight("sun", { rotation: [-40, 0, 30] })],
  environment: { type: "sky" },
});

// A viewer in any element
const viewer = new Viewer(document.querySelector("#view"), { scene, lightFollow: true });
viewer.on("frame", ({ samples }) => console.log(samples));
viewer.scene.objects[0].position[1] = 1; // mutate freely: the next frame restarts the render

// The whole editor
const editor = new Editor(document.querySelector("#app"), { storageKey: "my-scene" });
editor.on("change", ({ scene }) => save(scene));

// Thumbnails for your own UI
renderMaterialPreview(gold, document.querySelector("canvas.thumb"), { samples: 96 });

// Or register the custom elements yourself
import { defineElements } from "path-tracer-web";
defineElements(); // <pt-viewer>, <pt-editor>, <pt-material-preview>

Scene format

Plain JSON, versioned. Colors are sRGB hex strings, angles are degrees, and every primitive fits the unit cube so scale is its size in scene units. Missing fields get defaults through normalizeScene, so hand written scenes can stay short. 

{
  "version": 2,
  "name": "My scene",
  "camera": { "target": [0, 0.5, 0], "yaw": 20, "pitch": 15, "distance": 4, "fov": 38, "aperture": 0, "focusDistance": 0 },
  "environment": { "type": "sky", "zenith": "#4a7bc8", "horizon": "#c9d6e6", "ground": "#3a3632", "intensity": 0.45 },
  "render": { "maxBounces": 8, "maxSamples": 4096, "exposure": 0, "toneMapping": "aces", "clamp": 8 },
  "materials": [
    { "id": "gold", "name": "Gold", "baseColor": "#ffd27a", "metallic": 1, "roughness": 0.15,
      "specular": 0.5, "transmission": 0, "ior": 1.5, "clearcoat": 0, "clearcoatRoughness": 0.05,
      "emission": "#ffffff", "emissionStrength": 0, "pattern": "none", "patternColor": "#222222", "patternScale": 4 }
  ],
  "objects": [
    { "id": "ball", "name": "Ball", "shape": "sphere", "position": [0, 0.5, 0], "rotation": [0, 0, 0],
      "scale": [1, 1, 1], "materialId": "gold", "visible": true }
  ],
  "lights": [
    { "id": "sun", "name": "Sun", "type": "sun", "rotation": [-40, 0, 30], "color": "#fff4e0",
      "intensity": 2.4, "angle": 1, "enabled": true }
  ]
}

Shapes: sphere, box, cylinder, cone, plane, disk. Lights: area (size, faces its local -Y), sphere (radius), point, sun (angle). Theme the editor from your page with CSS custom properties such as --pt-accent, --pt-bg, --pt-panel and --pt-font.
